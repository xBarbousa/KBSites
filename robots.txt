#   https://kbsites.com.br/llms.txt
# and the full public text in Markdown is at
#   https://kbsites.com.br/llms-full.txt
#
# POLICY
# 1. Public pages (/, /terms.html, /privacy.html) and the files they need to
#    render (/fotos/) are open to every search engine and every AI crawler,
#    including AI training crawlers.
# 2. Form handlers, session and sign-in endpoints, user uploads and the admin
#    area are never crawled. Every group below disallows them.
# 3. The account portal (/account/, linked as "Log in") and the old /partners/
#    links that redirect into it must stay OUT OF SEARCH RESULTS. Every
#    /account/ page carries <meta name="robots" content="noindex,nofollow">.
#    Googlebot, Bingbot and Applebot honor noindex, so they may fetch /account/
#    and see it (a Disallow would hide the noindex and could leave the bare URL
#    in the index). Every other crawler is disallowed from /account/ and
#    /partners/.
# 4. Prospect previews (/clientes/) show real businesses that are NOT clients
#    yet. They must never be crawled or indexed, so EVERY group, search engines
#    included, disallows /clientes/. The preview pages do not carry a noindex
#    tag of their own; the server should also send
#    "X-Robots-Tag: noindex, nofollow, noarchive, noimageindex" for /clientes/.
#    If a /clientes/ URL ever shows up in Google or Bing, use the Search Console
#    / Bing Webmaster removal tool (a Disallow alone does not remove it).
# 5. robots.txt is not access control. Private data is protected on the server.
#
# MAINTENANCE: a crawler that matches a named group IGNORES the "*" group
# (RFC 9309, section 2.2.1). Each group repeats the full list of rules.
# When you add or remove a rule, change it in EVERY group.
